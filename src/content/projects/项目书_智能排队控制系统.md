# 基于 STM32 的智能排队控制系统

## 1. 项目简介

### 项目背景

随着医院、银行、食堂等公共场所业务办理需求的不断增加，传统人工排队方式容易出现排队秩序混乱、等待时间较长以及人员管理效率较低等问题。为了提高排队管理的自动化和智能化水平，设计并实现了一套基于 STM32 的智能排队控制系统。

系统以 STM32F103C8T6 为主控，通过红外对管检测通过人员，用继电器模拟闸机的开合，并配合 LCD1602、双色 LED 与蜂鸣器进行状态提示。整机采用"红外中断计数 + SysTick 时基 + 状态机调度"的软件结构，实现放行与限流两种状态的自动切换，从而完成对排队流程的自动化控制。

通过该项目，深入学习 STM32 嵌入式开发、GPIO 外设驱动、外部中断、SysTick 时基、并口 LCD 时序控制以及嵌入式状态机设计等技术。

### 项目目标

实现以下功能：

- 红外传感器检测是否有人经过，并对通过人数进行累加计数

- LCD1602 实时显示当前状态（放行 / 等待）与已通过人数

- 每放行 5 人自动进入限流状态，限流 3 秒后自动恢复放行

- 继电器模拟闸机，放行状态松开、限流状态吸合

- 双 LED 指示：放行状态绿灯慢闪（1s），限流状态红灯快闪（200ms）

- 蜂鸣器在限流状态持续鸣响提示

### 开发环境

- 主控芯片：STM32F103C8T6（Cortex-M3，72MHz）

- 开发工具：Keil MDK、VS Code

- 固件库：STM32F1xx HAL 库（寄存器 + HAL 混合编程）

- 下载工具：ST-Link

- 编程语言：C

### 主程序流程

1. `HAL_Init()` 初始化 HAL 库

2. `stm32_clock_init(RCC_PLL_MUL9)` 配置系统时钟为 72MHz

3. 依次初始化 LED、继电器、蜂鸣器、红外中断、LCD1602

4. LCD 显示初始状态 `PASS...`

5. 进入主循环，轮询三个任务：

   - `sensor_task()` 处理红外标志位、人数累加、状态切换

   - `led1_task()` / `led2_task()` 根据 SysTick 置位的标志翻转 LED

6. SysTick 中断每 1ms 执行 `systick_isr()`，运行状态机并维护软定时计数

关键设计点是**中断只置标志、主循环做处理**：红外中断和 SysTick 中断内部不做耗时操作，只设置 `ia_flag`、`led1_task_flag`、`led2_task_flag`，真正的 LCD 刷新等耗时动作留给主循环执行，避免长时间占用中断。

```c
int main(void)
{
    HAL_Init();                         /* 初始化HAL库 */
    stm32_clock_init(RCC_PLL_MUL9);     /* 配置时钟, 72Mhz */
    led_init();                         /* 初始化LED灯 */
    gate_init();                        /* 初始化继电器 */
    beep_init();                        /* 初始化蜂鸣器 */
    exti_init();                        /* 初始化红外传感器 */
    lcd1602_init();                     /* 初始化LCD1602 */

    lcd1602_show_line(1,2,"PASS...");

    while(1)
    {
        sensor_task();
        led1_task();
        led2_task();
    }
}
```

## 4. 核心功能实现

### 4.1 红外检测模块（外部中断）

功能描述：

红外传感器接 PB4，有人经过时输出低电平，触发下降沿中断，在中断回调中置位标志位 `ia_flag`，由主循环取用。

实现方式：

- PB4 配置为 `GPIO_MODE_IT_FALLING` 下降沿触发，内部上拉

- NVIC 优先级设为 (2, 0)，低于 SysTick，避免阻塞时基

- 中断回调内延时消抖后二次确认电平，滤除干扰

- 提供 `ia_flag_get()` 读取并自动清零，实现"读一次消费一次"的语义

关键代码：

```c
void exti_init(void)
{
    GPIO_InitTypeDef gpio_initstruct;
    __HAL_RCC_GPIOB_CLK_ENABLE();                           // 使能GPIOB时钟

    gpio_initstruct.Pin = GPIO_PIN_4;                       // 红外传感器对应的引脚
    gpio_initstruct.Mode = GPIO_MODE_IT_FALLING;            // 下降沿触发
    gpio_initstruct.Pull = GPIO_PULLUP;                     // 上拉
    HAL_GPIO_Init(GPIOB, &gpio_initstruct);

    HAL_NVIC_SetPriority(EXTI4_IRQn, 2, 0);                 // 设置中断优先级
    HAL_NVIC_EnableIRQ(EXTI4_IRQn);                         // 使能中断
}

void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin)
{
    delay_ms(20);                                           // 消抖
    if (GPIO_Pin == GPIO_PIN_4)
    {
        if(HAL_GPIO_ReadPin(GPIOB, GPIO_PIN_4) == GPIO_PIN_RESET)
            ia_flag = TRUE;                                 // 只置标志，不做耗时操作
    }
}

uint8_t ia_flag_get(void)
{
    uint8_t temp = ia_flag;
    ia_flag = FALSE;                                        // 读取即清零
    return temp;
}
```

### 4.2 状态机与人数统计

功能描述：

系统只有两个状态：`PASS_STATE`（允许通过）和 `WAIT_STATE`（限流等待）。每检测到一人通过则计数加一并刷新 LCD，累计 5 人后切入限流状态，限流 3 秒后自动回到放行状态。

状态转移图：

```text
            检测到 5 人通过
      ┌──────────────────────────┐
      │                          ▼
┌───────────┐              ┌───────────┐
│PASS_STATE │              │WAIT_STATE │
│ 绿灯 1s 闪 │              │ 红灯 200ms │
│ 闸机松开   │              │ 蜂鸣器响    │
│ 蜂鸣器关   │              │ 闸机吸合    │
│ 计数累加   │              │ 计数已清零  │
└───────────┘              └───────────┘
      ▲                          │
      └──────────────────────────┘
            wait_cnt 计满 3000ms
```

实现方式：

- 状态切换与人数判断放在 `sensor_task()`，由主循环调用

- 状态对应的输出动作（LED / 蜂鸣器 / 继电器）统一由 `systick_isr()` 每 1ms 刷新，保证输出与状态始终一致

关键代码：

```c
void sensor_task(void)
{
    // 检测有没有人通过
    if(ia_flag_get() == TRUE && state == PASS_STATE)
    {
        passenger++;                                        // 人数+1
        sprintf(message, "PASS...%02d/05",passenger);        // LCD显示状态
        lcd1602_show_line(1,1,message);
    }
    // 如果通过的人数满了5个
    if(passenger >= 5)
    {
        passenger = 0;                                      // 人数清零
        state = WAIT_STATE;                                 // 进入不允许通行状态
        lcd1602_show_line(1,1,"WAIL...00/05");              // LCD显示状态
    }
}
```

### 4.3 SysTick 软定时与多路"并行"闪灯

功能描述：

复用 HAL 的 1ms SysTick 中断作为系统统一时基，用软计数器实现不同频率的 LED 闪烁与 3 秒限流计时，无需额外定时器，也不使用任何阻塞延时。

实现方式：

- 在 `stm32f1xx_it.c` 的 `SysTick_Handler` 中，`HAL_IncTick()` 之后调用 `systick_isr()`

- 每个周期性动作各自维护一个计数器：`led1_task_cnt`（1000ms）、`led2_task_cnt`（200ms）、`wait_cnt`（3000ms）

- 计数满则置标志清零，实现"软件定时器"效果，多路任务互不阻塞

关键代码：

```c
void SysTick_Handler(void)
{
  HAL_IncTick();
  systick_isr();                                            // 1ms 系统时基
}

void systick_isr(void)
{
    // 如果是允许通行的状态
    if(state == PASS_STATE)
    {
        if (led1_task_cnt < 1000)                            // LED1以1秒的频率闪烁
            led1_task_cnt++;
        else
        {
            led1_task_flag = 1;
            led1_task_cnt = 0;
        }
        led2_off();                                          // LED2不闪烁
        beep_off();                                          // 蜂鸣器不响
        gate_off();                                          // 开闸
    }
    // 如果是不允许通行的状态
    else if(state == WAIT_STATE)
    {
        if (led2_task_cnt < 200)                             // LED2以200ms的频率闪烁
            led2_task_cnt++;
        else
        {
            led2_task_flag = 1;
            led2_task_cnt = 0;
        }
        led1_off();                                          // LED1不亮
        beep_on();                                           // 蜂鸣器响
        gate_on();                                           // 关闸
        if (wait_cnt < 3000)                                 // 计时3秒
            wait_cnt++;
        else
        {
            wait_cnt = 0;
            state = PASS_STATE;                              // 重新允许通行
            lcd1602_show_line(1,1,"PASS...");
        }
    }
}

void led1_task(void)
{
    if(led1_task_flag == 0)
        return;
    led1_task_flag = 0;
    led1_toggle();
}
```

### 4.4 LCD1602 并口显示模块

功能描述：

用 8 位并口方式驱动 LCD1602，显示通行状态与人数，如 `PASS...03/05`、`WAIL...00/05`。

实现方式：

- PA0~PA7 作为 D0~D7 数据总线，PB1/PB2/PB10 分别作为 RS/RW/EN 控制线

- 直接写 `GPIOA->ODR` 一次输出整字节，比逐位 `HAL_GPIO_WritePin` 更快也更简洁

- 初始化按标准时序：延时 15ms → 写 0x38 两次 → 0x08 关显示 → 0x01 清屏 → 0x06 光标右移 → 0x0C 开显示

- `lcd1602_show_line()` 通过 `0x80 + col` 与 `0x80 + 0x40 + col` 定位第一、第二行

关键代码：

```c
void lcd1602_write_cmd(char cmd)
{
    RS_LOW;                                 // RS=0 写指令
    RW_LOW;                                 // RW=0 写操作
    EN_LOW;
    GPIOA->ODR = cmd;                       // 把一字节数据放到GPIOA 8个引脚
    delay_ms(5);
    EN_HIGH;                                // EN上升沿锁存
    delay_ms(5);
    EN_LOW;
}

void lcd1602_show_line(char row, char col, char *string)
{
    switch(row){
    case 1:
        lcd1602_write_cmd(0x80+col);        // 最高位 D7 为高电平
        while(*string){
            lcd1602_write_data(*string);
            string++;
        }
        break;
    case 2:
        lcd1602_write_cmd(0x80+0x40+col);   // 第二行起始地址 0x40
        while(*string){
            lcd1602_write_data(*string);
            string++;
        }
        break;
    }
}
```

### 4.5 继电器、蜂鸣器与 LED 驱动

功能描述：

三者都是简单的 GPIO 输出控制，统一采用低电平有效的模块，封装成 `xxx_on()` / `xxx_off()` / `xxx_toggle()` 接口，屏蔽电平极性细节。

实现方式：

- 全部配置为 `GPIO_MODE_OUTPUT_PP` 推挽输出、`GPIO_SPEED_FREQ_HIGH`

- 初始化末尾立即调用 `off()`，保证上电后处于确定的安全状态（闸机松开、蜂鸣器静音）

- 继电器额外提供 `gate_status_get()` 读回引脚状态，便于调试确认闸机动作

关键代码：

```c
void gate_init(void)
{
    GPIO_InitTypeDef gpio_initstruct;
    __HAL_RCC_GPIOB_CLK_ENABLE();                           // 使能GPIOB时钟

    gpio_initstruct.Pin = GPIO_PIN_6;                       // 继电器对应的引脚
    gpio_initstruct.Mode = GPIO_MODE_OUTPUT_PP;             // 推挽输出
    gpio_initstruct.Pull = GPIO_PULLUP;                     // 上拉
    gpio_initstruct.Speed = GPIO_SPEED_FREQ_HIGH;           // 高速
    HAL_GPIO_Init(GPIOB, &gpio_initstruct);

    gate_off();                                             // 上电默认开闸
}

void gate_on(void)     // 闭合继电器（关闸）
{
    HAL_GPIO_WritePin(GPIOB, GPIO_PIN_6, GPIO_PIN_RESET);
}

void gate_off(void)    // 松开继电器（开闸）
{
    HAL_GPIO_WritePin(GPIOB, GPIO_PIN_6, GPIO_PIN_SET);
}
```

## 5. 项目难点与解决方案

### 问题一：红外传感器一次通过被计成多次

问题现象：

一个人经过红外对管，LCD 上人数一次跳 2~3 个，很快就凑满 5 人误触发限流。

分析过程：

1. 先怀疑代码逻辑，检查 `passenger++` 是否被重复调用 —— 逻辑只有一处，无重复

2. 用逻辑分析仪（示波器）观察 PB4 波形，发现遮挡瞬间存在多个毛刺跳变

3. 确认这是机械/光学层面的抖动：人体边缘经过时红外接收管输出在阈值附近来回跳变，产生多个下降沿

最终原因：

红外模块输出信号在跳变边沿存在抖动，每个抖动都被 EXTI 当成一次独立的下降沿中断。

解决方案：

在中断回调里加入 20ms 延时消抖，并二次读取引脚电平确认仍为低电平才置标志位：

```c
delay_ms(20);
if(HAL_GPIO_ReadPin(GPIOB, GPIO_PIN_4) == GPIO_PIN_RESET)
    ia_flag = TRUE;
```

同时把标志位读取封装成 `ia_flag_get()`，读取后立刻清零，保证一次通过只被消费一次。

收获：

理解了外部中断必须配合消抖处理，也认识到"读一次清零"的标志位模式在中断与主循环之间传递事件时非常实用。需要说明的是，在中断里 `delay_ms(20)` 属于折中做法，会占用中断时间，更规范的写法是在中断里只置标志、由主循环用软定时器完成消抖窗口判断，这一点已列入后续优化。

## 8. 项目总结

通过本项目，掌握了 STM32 GPIO 输入输出配置、外部中断与 NVIC 优先级管理、SysTick 时基与软定时器实现、LCD1602 并口时序驱动以及状态机驱动的嵌入式程序设计方法，独立完成了一套可实际运行的智能排队控制系统。

在开发过程中，从零搭建了 BSP 分层结构，逐个编写并调试了红外、LED、蜂鸣器、继电器与 LCD 驱动，并针对红外重复计数、LCD 乱码与闪烁、继电器干扰导致复位等问题进行了分析和解决。这些问题分别来自信号抖动、中断时序设计和电源完整性三个不同层面，排查过程加深了对"中断置标志、主循环处理"这一嵌入式核心模式的理解，也让我意识到软件正确并不等于系统可靠，硬件层面的电源与干扰同样需要重视。
